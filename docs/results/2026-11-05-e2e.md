## Lessons recorded 2026-11-05

- DeckCraft sizes a new text box to its text (28.8 pt minimum) and ignores the requested rect height; the renderer runs `format.autofit {mode: none}` and then `shape.setBounds` after every `insert.textBox`, otherwise the spatial gate measures boxes the layout code never asked for.
- The SlideForge spatial gate counts medium findings as advisory; only high and critical block. Card rects behind text count as overlaps, so the layouts use hairlines and explicit box heights instead.
